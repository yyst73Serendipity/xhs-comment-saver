Firebase 云同步配置手册

每位使用者都要创建自己的 Firebase 项目，评论和笔记才会彼此隔离。

开始之前

本项目使用 Firebase Spark 免费方案即可完成个人云同步。准备好 Chrome、Node.js、npm、一个 Google 账号，以及完整的项目源码。

重要：不要复用别人已经配置好的 Firebase 项目，也不要把 Google 密码、Firebase CLI 授权码或 AI API Key 写进配置文件。

1. 创建 Firebase 项目

  1. 打开 Firebase 控制台，点击“创建项目”。
  2. 填写一个只供自己使用的项目名称，保持 Spark 免费方案。
  3. Google Analytics 对本扩展不是必需项，可以关闭。

2. 注册 Web 应用

在“项目概览”点击 Web 图标 </> 注册应用。复制页面给出的 Firebase 配置，其中会包含 apiKey、authDomain、projectId、storageBucket、messagingSenderId 和 appId。

3. 启用 Google 登录

进入“构建 → Authentication → 登录方法”，选择 Google，开启该提供方，选择项目支持邮箱并保存。

4. 创建 Firestore

进入“构建 → Firestore Database”，创建 (default) Standard 数据库。选择“生产模式”，并选择离自己较近的区域。不要在控制台手动放宽安全规则。

5. 创建本机配置

在项目根目录执行：

cp config/firebase.example.json config/firebase.local.json

把 Web 应用配置写入新文件。第一次配置时保持 ownerUid 为空：

{
  "apiKey": "控制台中的 apiKey",
  "authDomain": "你的项目ID.firebaseapp.com",
  "projectId": "你的项目ID",
  "storageBucket": "控制台中的 storageBucket",
  "messagingSenderId": "控制台中的 messagingSenderId",
  "appId": "控制台中的 appId",
  "authPageUrl": "https://你的项目ID.web.app",
  "ownerUid": ""
}

config/firebase.local.json 只保存在本机，并已被 Git 忽略。

6. 登录 Firebase CLI 并部署登录页

npm install
npx firebase login
npm run build
npm run deploy:hosting

如果 CLI 的本机回调失败，可以改用 npx firebase login --no-localhost。此时只部署登录页，云端评论数据仍不会开放。

7. 加载扩展

  1. 打开 chrome://extensions，开启“开发者模式”。
  2. 点击“加载已解压的扩展程序”。
  3. 选择项目中的 dist/extension，不要选择源码根目录。
  4. 点击扩展图标，打开评论管理页。

8. 登录并取得 UID

  1. 在管理页点击“使用 Google 登录”，登录以后要用于同步的账号。
  2. 回到 Firebase 控制台，打开“Authentication → 用户”。
  3. 复制该账号对应的“用户 UID”。UID 是账号标识，不是密码。

9. 绑定 ownerUid 并部署规则

把刚复制的 UID 填入 config/firebase.local.json 的 ownerUid，然后执行：

npm run deploy

部署完成后，回到 chrome://extensions 点击扩展的“重新加载”，再重新打开管理页。只有这个 UID 对应的 Google 账号能够访问云端数据。

10. 迁移本机数据并验证

  1. 已有本机收藏时，点击“迁移本机数据”。
  2. 先下载 JSON 备份，确认文件已落盘，再点击“确认迁移”。
  3. 等待顶部状态显示“已同步”。
  4. 换一台电脑或另一个 Chrome 配置，加载同一份个人构建并登录同一账号，点击“立即同步”验证数据。

完成检查

  • 管理页顶部显示你的 Google 邮箱。
  • “立即同步”“迁移本机数据”和“清除本机缓存”可以使用。
  • 同步完成后显示最近同步时间。
  • 另一台设备登录同一账号后能够拉取评论、分类、笔记和 AI 总结。

常见问题

一直显示仅保存在本机：检查 firebase.local.json 是否填写完整，并重新运行 npm run build。

登录后同步按钮不可用：检查 ownerUid 是否填写，是否运行过 npm run deploy，以及扩展是否重新加载。

提示权限不足：确认当前登录账号在 Authentication 中的 UID 与 ownerUid 完全一致。

换电脑没有数据：确认使用的是同一份个人构建和同一个 Google 账号，然后点击“立即同步”。

是否收费：个人轻量使用通常可以保持在 Spark 免费额度内，实际用量请以 Firebase 控制台显示为准。
