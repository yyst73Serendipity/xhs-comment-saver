# 小红书评论收藏

浏览小红书时收藏和分类用户评论的 Chrome 浏览器插件。

## 功能

- **评论收藏**：在小红书帖子评论区自动注入收藏按钮和多选勾选框，支持单条或批量收藏
- **分类管理**：预设「未分类」「好物」「避雷」「搞笑」四个分类，支持自定义新建、重命名、删除
- **评论组**：批量收藏的多条评论共享同一组，管理页聚合展示，可展开/折叠上下文
- **独立管理页**：点击浏览器工具栏的扩展图标打开独立标签页，左侧分类栏 + 右侧评论列表
- **笔记功能**：每条收藏支持添加私人笔记，hover 显示，点击切换查看/编辑
- **搜索筛选**：按关键词搜索评论正文或作者，按分类筛选
- **分享卡片**：将评论生成复古风格图片卡片，支持 22 种纸张纹理模板
- **数据导入/导出**：支持 JSON 格式导出备份和导入合并
- **SPA 适配**：监听小红书单页路由变化，切换帖子时自动重新注入

## 启动方式

1. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions` 并回车
2. 在页面右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `xhs-comment-saver` 项目根目录，确认
5. 扩展图标会出现在浏览器工具栏中

### 使用方式

- **收藏评论**：打开任意小红书帖子页面，在评论区勾选评论，点击收藏按钮选择分类
- **查看收藏**：点击浏览器工具栏中的扩展图标，在新打开的标签页中管理和搜索收藏的评论
- **导出备份**：在管理页点击「导出」按钮下载 JSON 备份文件，点击「导入」合并已有备份

### 运行测试

在浏览器中打开 `chrome-extension://<扩展ID>/tests/storage.test.html`，点击「运行全部测试」按钮。

## 技术栈

- Chrome Extension Manifest V3
- 纯 HTML / CSS / JavaScript（无框架依赖）
- chrome.storage.local 存储
